# 教材课内知识索引（textbook_index）

## 背景

用户在本地下载了国家中小学智慧教育平台的教材 PDF（`/Users/shipeng/Desktop/国家中小学智慧教育平台教材`，31GB / 330 本，覆盖小学-高中四大学科多个版本），希望生成管线能结合课内知识来展开篇章内容，但文件太多太大，不可能整本塞进 LLM 上下文。

## 方案：只建目录索引，不做全文入库

- **不做**：把整本 PDF 转文字塞给 LLM、全文 OCR、向量数据库/embedding 检索（30~50 本书的目录规模，关键词匹配足够用，没必要上重型基础设施）。
- **做的**：解析每本教材的目录页，得到"章/节标题 + 起始页码"的轻量索引（JSON，几百 KB）。生成管线要用某一节内容时，再按需从 PDF 提取那几页原文（`pymupdf` + 乱码还原），不是全书常驻。

## 提取引擎：pymupdf（不是 pdftotext）

最初用 poppler 的 `pdftotext`，后来发现两个致命问题，全面切换到 `pymupdf`（Python 库 `fitz`）：
1. **NFD 路径问题**：pdftotext 遇到 macOS 特有的 NFD 分解文件名会报 "No such file or directory"，pymupdf 用 Python str 路径可以直接打开，不受影响。
2. **数学教材乱码**（下面详细说）：pdftotext 只能按 Unicode 码位输出，pymupdf 能拿到真实字体名，配合还原表才能解决。

## 数学教材"斜体乱码"问题——已定位根因并解决

用户反馈教材文字"好多都乱码"（如 `犃犫犮狓狔` 这类看起来像生僻汉字的字符）。**根因已查清**：这批人教版数学教材由"方正书版"排版系统制作，公式里的斜体拉丁字母变量（x, y, a, b, A, B...）使用专有字体 `E-BX9`（业内俗称"白斜体/BX字体"），编码表把拉丁字符映射到 CJK 统一表意文字区的冷僻汉字码位上——这是已知的行业问题（搜"方正书版 白斜 BX字体"能查到多篇讨论），poppler/pdftotext 等通用工具都不认识这层私有映射。

**解决方法**：`scripts/fzsp_font_fix.py` 建立了完整的还原映射表。验证方法不是猜测，而是：
1. 用 pymupdf 提取真实字体名，筛出白斜体（含"BX"关键字）span；
2. 在人教A版《数学必修第一册》全书 269 页范围内，收集每个乱码字符的真实上下文语境（如"犚"必出现在"实数集犚""狓∈犚"这类强语义场景，锁定对应 R；"犈犉犌犎"是矩形四个顶点连用，锁定 E/F/G/H）；
3. 26 个小写字母 + 21 个大写字母（A-V）全部有直接语境证据验证；W/X/Y/Z 因样本书未出现全部大写字母，按同一字体区连续码位推断，标注为置信度略低。

**效果**：用户报告的原始乱码段落（"设这个矩形的一条边长为狓ｍ...犪狓２＋犫狓＋犮＞０"）还原后完全正确可读（"设这个矩形的一条边长为xm...ax2+bx+c>0"）。已在物理/化学/生物教材上抽样验证：这几科教材本身用普通字体排版（只有数学公式密度最高才用了这套私有字体），pymupdf 直接提取就是干净文本，还原表对它们无副作用。

**仍存在的次要问题**：根号符号 `√`、部分段落标记等**符号类**（非字母）私有字符还没有对应的还原表（如 `槡` 应为 √），优先级低于字母乱码，未来如有需要可用同样方法（真实语境交叉验证）补充。

## 当前范围（MVP）

只索引人教系教材（`download_manifest.csv` 里 `edition` 含"人教"的 55 本，覆盖小学数学、初中数理化生、高中数理化生），因为：
1. 人教系是国内使用最广、覆盖学段学科最全的版本；
2. 当前 `edu-agent` 生成管线里 `GEN_PROMPT` 的课标诚实性规则默认也是对齐人教版；
3. 全量 330 本先跑通流程验证质量，再决定是否扩展到苏教版/北师大版等其他版本（脚本已支持 `python3 build_index.py --scope all` 一键切换全量）。

## 实测结果（2026-08-24 最终版）

- 55 本人教系教材，**42 本成功解析出目录结构**（初中/高中数理化生 25/25 全部成功，数学 17/30），**13 本失败**
- 章节总数 170 章、子节总数 558 节
- **按学科成功率**：物理 9/9、化学 7/7、生物 9/9（全部 100%）；数学 17/30（小学低年级 12 本 + 3 本纯图片扫描/特殊私有字体的高中教材属于长尾情况，见下）
- 目录解析已覆盖 6 类子节编号格式（数学两级"1.1"/物理单级"2."/化学中文"第一节"/生物"第1节"/化学"课题N"/B版数学三级"1.1.2"）+ 3 类版式（同行/跨行/分栏错位，分栏又分页码列在前/标题列在前两种子序）+ B'类"章标题无独立页码，靠第一个子节回填"
- 修复了一个隐蔽 bug：B 版数学教材封面里混进过一段物理教材的残留文字（"第五章 抛体运动"，模板复用出错），如果直接按"最早出现的'目录'字样"定位会把这行装饰文字误判成第一章、挤掉真正的第一章——现在改用"目录"二字独占一整行的位置精确定位

## 已知限制（诚实记录，未来遇到问题先查这里）

1. **小学数学低年级（12本）无法解析目录**：一/二/三/四/五/六年级数学教材的目录页大量使用"配图+散落数字"排版（如"1 分数乘法 2 位置 19"这种数字和标题交错、无固定分隔规律），且部分章节标题本身很短（"比""圆"）容易和普通文字混淆，当前基于正则的解析器不适用，需要专门的版式识别（比如按坐标聚类），暂未投入。
2. **B版数学（7本长尾）**：目录顶层直接是"3.1 排列与组合"这种子节编号，没有独立的"第X章"目录条目（章名只在正文页眉出现），且这套版式还用了另一种未在其他教材出现过的私有字体（如页眉里的 `!"#$%&'()*+,-./` 这类符号串，尚未破解含义）。这7本占B版数学全部册次，不影响当前四篇章内容（均未涉及B版教材），暂列为已知限制。
3. **符号类乱码未处理**：根号 √ 等符号（非拉丁字母）在部分数学教材里也走了类似的私有字体映射（如 `槡`→√），当前还原表只覆盖 a-z/A-Z 字母，符号类暂未处理。
4. **印刷页码 ≠ PDF 实际页序**：教材正文页码是从"第1页"开始印的，但 PDF 文件前面有封面/扉页/编者寄语等不计入印刷页码的页。`build_index.py` 里的 `calibrate_offset()` 会自动探测偏移量，但校准不是100%可靠——个别目录排版特殊的书仍可能算错，使用索引结果前建议先用 `get_page_text` 抓一下开头几行确认内容对不对，不要盲信。
5. **NFD 文件名**：macOS 下这批文件名是 Unicode NFD 分解形式，Python 里手写的 NFC 字符串路径匹配不到磁盘文件。必须用 `glob.glob()` 或 `build_index.py` 里的 `real_path()` 函数转换成真实路径再使用（这个问题对 pymupdf 本身不影响，但 `download_manifest.csv` 里记录的路径仍需转换）。
6. **纯图片扫描版 PDF**：个别教材（如某本 132MB 的"数学（A版）必修第二册"）完全没有文字层，pymupdf 也提取不出任何内容，需要 OCR 才能处理，超出当前方案范围。

## 文件结构

```
textbook_index/
  scripts/
    build_index.py     # 索引构建器：pymupdf解析目录+校准页码偏移，写出 index_data/*.json
    lookup.py           # 查询工具：关键词找章节 + 按页码范围提取原文，供 server.py 生成管线调用
    fzsp_font_fix.py    # 方正书版斜体乱码还原表（a-z/A-Z 完整映射，经全书真实语境验证）
  index_data/
    index_renjiao.json  # 人教系55本教材的索引（章节标题/页码/文件路径）
  preview_server.py     # 独立体验页（端口8770），搜关键词看命中章节+课本原文
```

## 用法

```bash
# 重新构建索引（教材文件有更新，或想扩展到全部330本时）
cd scripts && /Users/shipeng/.workbuddy/binaries/python/envs/default/bin/python3 build_index.py
# 全量330本（含非人教版本）：
python3 build_index.py --scope all

# 查询某个知识点对应课本哪一节
cd scripts && /Users/shipeng/.workbuddy/binaries/python/envs/default/bin/python3 lookup.py "万有引力"

# 启动可视化体验页
cd .. && /Users/shipeng/.workbuddy/binaries/python/envs/default/bin/python3 preview_server.py
```

在生成管线（`server.py`）里调用：
```python
import sys
sys.path.insert(0, ".../textbook_index/scripts")
from lookup import find_chapter, get_page_text, hit_range

hits = find_chapter("万有引力", subject="物理", stage="高中")
if hits:
    start, end = hit_range(hits[0])
    ref_text = get_page_text(hits[0]["path"], start, end)
    # 把 ref_text 的关键句摘引进 GEN_PROMPT，而不是整段照搬
```

**注意**：`build_index.py`/`lookup.py` 依赖 `fitz`（pymupdf）库，运行时需用装了这个库的 Python 环境（`/Users/shipeng/.workbuddy/binaries/python/envs/default/bin/python3`），不能用系统默认 Python。
