# 直观理解

积分这个概念可以从两个不同的角度来理解，它们恰好对应了积分的两种基本类型。

**角度一：累积量的计算（定积分）**

想象你正在记录一个水龙头的水流速度——每分钟流出的水量在不断变化。你想要知道从第 0 分钟到第 10 分钟总共流出了多少水。如果水流速度是恒定的，直接"速度×时间"即可。但速度在变，怎么办？一个朴素的想法是：把时间轴切成极小的片段，在每个小片段内近似认为速度不变，算出该片段的水量，然后把所有片段加起来。切得越细，结果越精确。当片段无限细时，这个和就趋近于一个精确值——这就是**定积分**的核心思想："分割、近似、求和、取极限"。

从几何上看，如果函数图像是一条曲线，定积分 $\int_a^b f(x)\,dx$ 就是计算曲线下方从 $x=a$ 到 $x=b$ 的区域面积。这里的 $dx$ 象征着"无穷小的宽度"，$f(x)$ 是"高度"，积分就是把这些无穷小的矩形面积累加起来。

**角度二：求原函数（不定积分）**

不定积分思考的是一个相反的问题：已知一个函数的导数，求这个函数本身。例如，我们知道 $2x$ 的导数是 $2$，那么谁的导数是 $2x$？答案是 $x^2$（当然，$x^2+1$、$x^2-5$ 等也都是，因为常数项求导后消失）。所以 $2x$ 的不定积分是 $x^2 + C$，其中 $C$ 是任意常数，称为积分常数。

这个角度下，积分是微分的逆运算——就像加法和减法、乘法和除法互为逆运算一样。因此不定积分也称为"反导数"（antiderivative）。

# 严格定义

### 定积分（黎曼积分）

设函数 $f(x)$ 在闭区间 $[a, b]$ 上有定义。对 $[a, b]$ 做分割：

$$a = x_0 < x_1 < x_2 < \cdots < x_n = b$$

在每个子区间 $[x_{i-1}, x_i]$ 上任取一点 $\xi_i$，作黎曼和：

$$S = \sum_{i=1}^{n} f(\xi_i)\,\Delta x_i \quad (\Delta x_i = x_i - x_{i-1})$$

如果当所有子区间长度的最大值 $\lambda = \max\{\Delta x_i\} \to 0$ 时，黎曼和 $S$ 趋于一个确定的极限值 $I$，且该极限与分割方式和 $\xi_i$ 的取法无关，则称 $f(x)$ 在 $[a, b]$ 上**可积**，该极限值 $I$ 称为 $f(x)$ 在 $[a, b]$ 上的**定积分**，记作：

$$\int_a^b f(x)\,dx = \lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i)\,\Delta x_i$$

其中 $a$ 是积分下限，$b$ 是积分上限，$f(x)$ 是被积函数，$x$ 是积分变量。

**可积的充分条件**：闭区间上的连续函数必可积；有界且只有有限个间断点的函数也可积。

### 不定积分

若在区间 $I$ 上，$F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 的一个**原函数**。$f(x)$ 的全体原函数称为 $f(x)$ 的**不定积分**，记作：

$$\int f(x)\,dx = F(x) + C$$

其中 $C$ 为任意常数，称为积分常数。

### 基本积分公式（部分）

- $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C \quad (n \ne -1)$
- $\int \dfrac{1}{x}\,dx = \ln|x| + C$
- $\int e^x\,dx = e^x + C$
- $\int \sin x\,dx = -\cos x + C$
- $\int \cos x\,dx = \sin x + C$
- $\int \dfrac{1}{1+x^2}\,dx = \arctan x + C$

# 典型例子

### 例 1：不定积分——求幂函数的原函数

计算 $\displaystyle\int x^2\,dx$

解：根据基本积分公式 $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$（$n \ne -1$），令 $n = 2$：

$$\int x^2\,dx = \frac{x^3}{3} + C$$

验证：对结果求导，$\left(\dfrac{x^3}{3}\right)' = \dfrac{3x^2}{3} = x^2$ ✓

### 例 2：定积分——计算曲线下的面积

计算 $\displaystyle\int_0^1 x^2\,dx$，即抛物线 $y = x^2$ 在 $[0, 1]$ 上与 $x$ 轴围成的面积。

法一（用定义——黎曼和）：
将 $[0, 1]$ 等分成 $n$ 份，每份宽度 $\Delta x = \dfrac{1}{n}$，取右端点 $\xi_i = \dfrac{i}{n}$，则：

$$S_n = \sum_{i=1}^{n} \left(\frac{i}{n}\right)^2 \cdot \frac{1}{n} = \frac{1}{n^3} \sum_{i=1}^{n} i^2 = \frac{1}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}$$

当 $n \to \infty$ 时，$S_n \to \dfrac{1}{3}$。

法二（用微积分基本定理——推荐）：
已知 $x^2$ 的一个原函数是 $F(x) = \dfrac{x^3}{3}$，则：

$$\int_0^1 x^2\,dx = F(1) - F(0) = \frac{1^3}{3} - 0 = \frac{1}{3}$$

### 例 3：物理应用——位移计算

某物体沿直线运动，速度 $v(t) = 3t^2$（m/s），求从 $t = 0$ 到 $t = 2$ 秒的位移。

解：位移 $= \displaystyle\int_0^2 3t^2\,dt = \left[t^3\right]_0^2 = 8 - 0 = 8$ 米。

### 例 4：常用技巧——换元积分

计算 $\displaystyle\int 2x \cos(x^2)\,dx$

令 $u = x^2$，则 $du = 2x\,dx$，原积分变为：

$$\int \cos u\,du = \sin u + C = \sin(x^2) + C$$

# 微积分基本定理

微积分基本定理（Fundamental Theorem of Calculus, FTC）是连接微分与积分的桥梁，也是整个微积分学的核心。它分为两部分：

### 第一基本定理（原函数的存在性）

设 $f$ 在 $[a, b]$ 上连续，定义函数 $F(x) = \displaystyle\int_a^x f(t)\,dt$（即变上限积分函数），则 $F(x)$ 在 $[a, b]$ 上可导，且 $F'(x) = f(x)$。

换言之：**对连续函数取定积分（变上限），得到的是被积函数的一个原函数。**

这个定理告诉我们：任何一个连续函数都有原函数，而且原函数可以通过定积分来构造。

### 第二基本定理（定积分的计算）

设 $f$ 在 $[a, b]$ 上连续，$F$ 是 $f$ 的任意一个原函数（即 $F' = f$），则：

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

这就是大名鼎鼎的**牛顿-莱布尼茨公式**。它告诉我们：要计算定积分，只需找到被积函数的一个原函数，然后代入上下限求差即可，完全不需要回到繁琐的黎曼和定义。

### 直观理解

第一定理说"积分再微分回到原函数"，第二定理说"微分再积分得到原函数的变化量"。两者合在一起，揭示了微分与积分互为逆运算的本质：

- $\dfrac{d}{dx}\left[\displaystyle\int_a^x f(t)\,dt\right] = f(x)$ （先积后导，还原）
- $\displaystyle\int_a^b F'(x)\,dx = F(b) - F(a)$ （先导后积，得到净变化）

### 历史意义

在微积分基本定理出现之前，求面积（定积分）和求切线（导数）是两门完全独立的学问。牛顿和莱布尼茨独立发现了它们之间的联系，从而统一了微积分，使之成为一门强有力的数学工具。这也是为什么这门学科叫"微积分"（Calculus）——它把"微分"和"积分"这两个看似无关的运算联系在了一起。
