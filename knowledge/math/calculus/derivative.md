# 直观理解

导数描述的是函数曲线在某一点"陡峭"或"平缓"的程度。可以把它想象成开车时仪表盘上的速度表读数：路程随时间变化的快慢，就是路程对时间的导数。

## 几何意义

在曲线 $y = f(x)$ 上，某点 $x_0$ 处的导数 $f'(x_0)$ 等于曲线在该点切线的斜率。

## 物理意义

如果 $s(t)$ 是位移随时间变化的函数，那么 $s'(t)$ 就是瞬时速度；再求一次导数得到瞬时加速度。

# 严格定义

设函数 $f(x)$ 在点 $x_0$ 的某邻域内有定义，当自变量从 $x_0$ 变化到 $x_0+\Delta x$ 时，若极限

$$\lim_{\Delta x \to 0} \frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$

存在，则称该极限为 $f$ 在 $x_0$ 处的导数，记作 $f'(x_0)$。

# 典型例子

- $f(x) = x^2$，则 $f'(x) = 2x$。在 $x=1$ 处导数为 $2$，意味着曲线在该点切线斜率为 $2$。
- $f(x) = \sin x$，则 $f'(x) = \cos x$。
- $f(x) = e^x$，则 $f'(x) = e^x$（导数等于自身的特殊性质）。

# 易错点

学生最常见的混淆是把"在某点连续"和"在某点可导"画等号。事实上：

- **可导一定连续**：若 $f$ 在 $x_0$ 可导，则必然在 $x_0$ 连续。
- **连续不一定可导**：典型反例 $f(x) = |x|$ 在 $x=0$ 处连续但不可导（左右导数不相等）。

讲解时建议先强调"可导是比连续更强的条件"，再用 $|x|$ 这个反例巩固。
