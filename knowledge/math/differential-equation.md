# 直观理解

**微分方程**（Differential Equation）是一个包含未知函数及其导数的方程。通俗地说，普通的代数方程问的是"这个数是多少"，而微分方程问的是"这个东西怎么变"——它描述了变化率与状态量之间的关系。

**为什么需要微分方程？** 在自然界中，我们往往更容易观察到"变化的规律"而非"量本身"。例如：

- 一杯热咖啡放在房间里冷却：温度下降的速度（变化率）正比于咖啡与室温的温差。
- 一个种群的增长：人口增加的速度正比于当前人口总数。
- 弹簧上物体的振动：加速度（位置的变化率的变化率）正比于位移，方向相反。

这些规律都不能直接告诉我们"温度是多少"或"位置在哪里"，但它们精确描述了"温度如何变化""位置如何变化"。微分方程就是用来表达这类"变化规律"的数学语言，而"解微分方程"就是从变化规律反推出状态量本身。

**类比**：如果说导数是"瞬时的变化率"，那么微分方程就是"变化率应该满足的规则"——好比给了一个导航指令："你的速度始终等于你当前位置的某个函数"，然后由你来反推出整个运动轨迹。

# 严格定义

### 基本定义

设 $y = y(x)$ 是自变量 $x$ 的未知函数。一个**常微分方程**（Ordinary Differential Equation, ODE）是联系自变量 $x$、未知函数 $y(x)$ 及其各阶导数的等式：

$$F(x, y, y', y'', \dots, y^{(n)}) = 0$$

如果方程中的未知函数是多元函数，且包含偏导数，则称为**偏微分方程**（Partial Differential Equation, PDE）。

### 阶

微分方程的**阶**（order）是方程中出现的最高阶导数的阶数。例如：

- $y' = 2x$ 是一阶方程；
- $y'' + \omega^2 y = 0$ 是二阶方程；
- $y''' - 3y'' + 3y' - y = 0$ 是三阶方程。

### 线性与非线性

若 $F$ 关于 $y, y', y'', \dots, y^{(n)}$ 是**一次式**（即没有 $y^2$、$(y')^3$、$y y''$ 等项），则称方程为**线性微分方程**，否则为**非线性微分方程**。

一般的 $n$ 阶线性微分方程形式为：

$$a_n(x) y^{(n)} + a_{n-1}(x) y^{(n-1)} + \dots + a_1(x) y' + a_0(x) y = g(x)$$

### 通解与特解

- $n$ 阶微分方程的**通解**（general solution）含有 $n$ 个独立的任意常数。
- 给定 $n$ 个初始条件（如 $y(x_0) = y_0, y'(x_0) = y_1, \dots$）后，可以确定这些常数的具体值，得到**特解**（particular solution）。
- 有时微分方程还存在不包含在通解中的解，称为**奇解**（singular solution）。

### 初值问题

一个 $n$ 阶微分方程连同 $n$ 个初始条件，合称为**初值问题**（Initial Value Problem, IVP）：

$$\begin{cases}
F(x, y, y', \dots, y^{(n)}) = 0 \\
y(x_0) = c_0, \; y'(x_0) = c_1, \; \dots, \; y^{(n-1)}(x_0) = c_{n-1}
\end{cases}$$

# 典型例子

### 例 1：指数增长与衰减（一阶线性）

最简单的微分方程之一：

$$\frac{dy}{dt} = r y$$

其中 $r$ 是常数。这个方程说："函数的变化率正比于函数本身"。

**解法**：分离变量 $\displaystyle\frac{dy}{y} = r\,dt$，两边积分得 $\ln|y| = rt + C$，所以：

$$y(t) = C e^{rt}$$

若给定初值 $y(0) = y_0$，则 $y(t) = y_0 e^{rt}$。

**应用**：放射性衰变（$r < 0$）、人口增长（$r > 0$）、复利计算、RC 电路放电等。

### 例 2：简谐运动（二阶线性）

弹簧振子的运动服从胡克定律：$F = -kx$，由牛顿第二定律 $F = ma = m\dfrac{d^2x}{dt^2}$ 得：

$$m\frac{d^2x}{dt^2} = -kx \quad \Longrightarrow \quad \frac{d^2x}{dt^2} + \omega^2 x = 0 \quad (\omega^2 = \tfrac{k}{m})$$

**解法**：这是一个常系数齐次线性微分方程。设 $x = e^{\lambda t}$，代入得特征方程 $\lambda^2 + \omega^2 = 0$，解得 $\lambda = \pm i\omega$，因此：

$$x(t) = C_1 \cos(\omega t) + C_2 \sin(\omega t)$$

或等价地 $x(t) = A\cos(\omega t + \varphi)$，其中 $A$ 为振幅，$\varphi$ 为初相位，$\omega$ 为角频率。

**应用**：弹簧振子、单摆（小角度近似）、LC 振荡电路、分子振动。

### 例 3：牛顿冷却定律

物体温度 $T(t)$ 的变化率正比于物体温度与环境温度 $T_0$ 的温差：

$$\frac{dT}{dt} = -k(T - T_0)$$

令 $u(t) = T(t) - T_0$，则 $\dfrac{du}{dt} = -k u$，化为指数衰减模型，解得：

$$T(t) = T_0 + (T(0) - T_0) e^{-kt}$$

这说明物体的温度呈指数方式趋近环境温度。

### 例 4：一阶线性微分方程（积分因子法）

更一般的一阶线性微分方程形式为：

$$\frac{dy}{dx} + P(x)y = Q(x)$$

两边乘以积分因子 $\mu(x) = e^{\int P(x)\,dx}$ 后，左边恰为 $\dfrac{d}{dx}[\mu(x) y]$，于是：

$$y = \frac{1}{\mu(x)} \int \mu(x) Q(x)\,dx$$

**应用**：RL 电路（$L\frac{di}{dt} + Ri = E$）、混合问题、一阶化学反应动力学。

# 一阶微分方程的初等解法

并非所有微分方程都能用初等方法求解，但以下几类一阶微分方程有系统的解法。

### 可分离变量方程

若方程可写成 $\dfrac{dy}{dx} = g(x)h(y)$ 的形式，则移项后两边积分：

$$\int \frac{dy}{h(y)} = \int g(x)\,dx$$

### 一阶线性微分方程

形如 $\dfrac{dy}{dx} + P(x)y = Q(x)$，使用积分因子法（如典型例子例 4 所述）。

### 齐次方程

若方程可写成 $\dfrac{dy}{dx} = f\left(\dfrac{y}{x}\right)$，则令 $u = \dfrac{y}{x}$，化为可分离变量方程。

### 恰当方程

形如 $M(x,y)\,dx + N(x,y)\,dy = 0$，若满足 $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$，则存在势函数 $\Phi(x,y)$ 使得 $d\Phi = M\,dx + N\,dy$，通解为 $\Phi(x,y) = C$。

这些初等解法构成了常微分方程课程的起点，也是许多物理和工程建模问题的基本工具。
