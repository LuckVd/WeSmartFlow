# 直观理解

函数就是一台"机器"：你喂给它一个输入 $x$，它返回一个输出 $f(x)$。同样的输入永远对应同样的输出，这是函数最核心的"单值"特性。

# 严格定义

设 $A, B$ 是两个非空集合。如果存在某种法则 $f$，使得对 $A$ 中每一个元素 $x$，按法则 $f$ 在 $B$ 中都有唯一确定的元素 $y$ 与之对应，则称 $f$ 是从 $A$ 到 $B$ 的一个函数，记作 $y = f(x)$。

- $A$ 称为定义域；
- $\{f(x) \mid x \in A\}$ 称为值域。

# 常见函数类型

- **线性函数**：$f(x) = ax + b$
- **多项式函数**：$f(x) = a_n x^n + \cdots + a_0$
- **指数函数**：$f(x) = a^x$（$a > 0, a \neq 1$）
- **三角函数**：$\sin x, \cos x, \tan x, \ldots$

# 易错点

- "$y$ 是 $x$ 的函数"**不要求**反过来 $x$ 也是 $y$ 的函数。例如 $y = x^2$ 中，$x = \pm\sqrt{y}$ 一对二，不是函数。
- 定义域是函数的本质组成部分。$f(x) = \sqrt{x}$ 和 $g(x) = \sqrt{x}$ 在 $[0, \infty)$ 上才有定义，**不是**对所有实数都有定义。
